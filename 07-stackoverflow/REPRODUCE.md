# Reproducing the charts

Everything starts from the public Stack Exchange data dump
(<https://archive.org/details/stackexchange>). Download it, then set the archive
paths at the top of the parsing scripts (`xml_to_parquet.py`, `parse_postlinks.py`,
`users_parse.py`) to wherever you unpacked `Posts.xml`, `PostLinks.xml`, `Users.xml`.

Requirements: Python with `pandas`, `numpy`, `pyarrow`, `matplotlib`, and the
Lora font (paths hard-coded in the chart scripts). Intermediate data
(`.parquet`, `.csv`, `.npy`, `.npz`) is regenerated by the pipeline below and is
intentionally not committed.

## 1. Archive -> parquet (do once)
```
python xml_to_parquet.py        # Posts.xml   -> posts_1.parquet, posts_2.parquet
python parse_postlinks.py       # PostLinks.xml -> duplicate_ids.npy, dup_target_ids.npy, link_in_counts.npz
python users_parse.py           # Users.xml   -> users.parquet
python build_tag_month_counts.py# posts       -> tag_month_counts.parquet, top10k_tags.csv
```

## 2. Intermediate series
```
python compute_good_posts.py       # -> monthly_good_posts.csv
python compute_frozen_genuine.py   # -> monthly_frozen.csv, frozen_saturation_trend.csv
python classify10k.py              # top10k_tags.csv -> tag_classification_10k.csv
python classify_extended.py        # -> tag_classification_extended.csv (+ tag_categories_extended.csv)
python survival.py                 # posts + users.parquet -> survival.csv
python hostility.py                # -> hostility_cohorts.csv, hostility_rates.csv
```

## 3. Charts (each writes a PNG)
| chart in the post | script | data it reads |
|---|---|---|
| `genuine_vs_all.png` | `genuine_vs_all_chart.py` | `monthly_good_posts.csv` |
| `saturation.png` | `saturation_chart.py` | `monthly_frozen.csv`, `frozen_saturation_trend.csv` |
| `tag_heatmap.png` | `tag_heatmap_chart.py` | `tag_month_counts.parquet`, `tag_classification_extended.csv` |
| `survival.png` | `survival_chart.py` | `survival.csv` |
| `hostility.png` | `hostility_chart.py` | `hostility_cohorts.csv` |
